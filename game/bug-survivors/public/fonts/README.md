# Fonts used by the player's guide (guide.html)

Self-hosted so the guide makes no request to Google (and so the strict Content-Security-Policy needs no exceptions).
Latin subset only (the guide is English), woff2. All SIL Open Font License 1.1.

- IBM Plex Mono 400, 600 and IBM Plex Sans (variable 400-700, plus 400 italic): https://github.com/IBM/plex
- Press Start 2P 400: https://github.com/codeman38/PressStart2P

Fetched on 2026-10-20 from Google Fonts (css2 API, `latin` subset). The @font-face rules are in `tools/guide_template.html`.
